# 会計仕様書

Serendipity-J 会計・店舗収支AIが従う会計上の正式ルールを定義します。`accounting/CLAUDE.md` の「金額基準ルール(税抜基準)」の詳細版であり、具体的な実装(スクリプト)や転記仕様を検討する際はこの仕様書を基準にしてください。実際の売上・経費の数値は記載しません(数値そのものは `accounting/output/` 配下のGit管理対象外領域で扱います)。

## 1. 基本原則:税抜基準

Serendipity-Jでは、会社の損益計算・店舗収支・経営管理上の売上は原則すべて「税抜金額」で計算します。

適用範囲:

- 損益計算(店舗別・全社)
- 店舗別売上
- 全社売上
- 物販売上
- 経費(家賃・人件費・広告費・仕入れ・その他)

人件費など性質上消費税の対象とならない項目は、そのままの金額を用います(税抜変換の対象外)。

## 2. 税込データからの変換方針

日報や外部データが税込金額でしか取得できない場合、消費税を適切に分離して税抜金額へ変換します。ただし、以下の条件をすべて満たす場合に限ります。

1. **対象取引の税率が根拠を持って確定できること。** 「おそらく標準税率だろう」といった推測での確定は禁止します。
2. **根拠は次のいずれかから得ること。**
   - 商品マスタ・コースマスタ上の税区分(例:標準税率10% / 軽減税率8%の指定)
   - 取引区分(施術・物販・回数券など)ごとに税率が一意に定まる業務ルール
   - 日報上に記載された税区分・消費税額そのもの
3. **税率が確定できない場合は、変換を行わず「要確認」として報告する。** 「税込金額 ÷ 1.1」のような一律変換は、対象取引がすべて標準税率であると確定している場合以外は行いません。軽減税率8%対象(物販の一部品目など)が混在し得るため、一律除算は禁止します。

### 税率混在への対応

施術売上と物販売上では、適用税率が異なる可能性があります。

- 施術(役務提供)は標準税率10%が一般的だが、日報・契約上の記載で確認すること。
- 物販(商品販売)は、軽減税率8%対象品(飲食料品等)と標準税率10%対象品が混在し得るため、商品ごとの税区分を商品マスタで確認すること。
- 店舗の日報に、標準税率分・軽減税率分を分けて集計している欄がある場合は、その内訳を優先的に使用する。

## 3. 日報側の消費税額との整合性確認

日報側に消費税額(または税率ごとの内訳)が記録されている場合、以下を必ず行います。

- 会計AIが計算で導出した消費税額と、日報記載の消費税額を突き合わせる。
- 一致しない場合は、転記や損益計算を完了扱いにせず、差分として報告する。
- 日報側の消費税額を無断で修正しない(日報は原則読み取り専用)。

## 4. 内部データ設計の原則

- 集計・検算の内部データ構造では、税込金額(`amount_incl_tax` 相当)と税抜金額(`amount_excl_tax` 相当)を別フィールドとして保持し、同じフィールド・同じ列に両方を混在させない。
- 消費税額そのもの(`tax_amount` 相当)も、可能な限り税率区分(標準10% / 軽減8%)ごとに分けて保持する。
- 変換を行った場合は、変換前(税込)・変換後(税抜)・適用した税率・判定根拠をセットで記録する(検算・監査のため)。

## 5. 出力時の表記ルール

- 転記案、報告、ログなどで金額を提示する際、税抜金額であることが文脈上自明でない場合は「(税抜)」等のラベルを明示する。
- 「2026 売上現状」「2026店舗収支」への転記仕様は、この税抜基準に沿って設計する。転記先の既存の運用が税込ベースになっている可能性がある場合は、無断で基準を変えず、オーナーに確認してから転記仕様を確定する。

## 6. 現状把握している税情報ソース(守山店の例・2026-09-10時点)

具体的な数値は含みませんが、今後の店舗展開時の参考として、税情報がどこにあるかを記録します。

- 日報(`①8月.xlsx`)の `基本情報` シート:コース・商品ごとに「販売価格(税込)」「販売価格(税別)」「消費税掛率(標準税率1.1 / 軽減税率1.08)」の列がある。品目ごとの税率判定に使える可能性がある。
- 日報の `月報集計` シートに、日付ごとの「標準税率」「軽減税率」それぞれの金額(月合計を含む)を集計した表がある。これが消費税額そのものか、税率区分ごとの税込/税抜金額の一部なのかは、実地確認が必要(下記「未確認事項」参照)。

## 7. 未確認事項

- `月報集計` の「実売(目標/実績)」「施術(目標/実績)」等の主要な売上数値が、税込・税抜のどちらで記録されているか未確認。
- `月報集計` の「標準税率」「軽減税率」の日別表が、消費税額そのものを表しているのか、他の意味(課税対象額など)を表しているのか未確認。
- 「2026 売上現状」の新規・既存・物販の金額が、税込・税抜のどちらで運用されているか未確認。
- 「2026店舗収支」の売上系行(施術売上・物販売上・売上合計)は現状ほぼ未入力のため、今後入力される際の税込・税抜の運用方針が未確定。この仕様書の税抜基準を適用してよいか、事前にオーナーに確認する。
- 経費側(家賃・人件費・広告費・仕入れ等)についても、日報・請求書等の金額が税込・税抜のどちらで記録されているか、科目ごとに未確認。

これらが確認できるまで、税込→税抜の自動変換を伴う転記・損益計算は実行しません。
