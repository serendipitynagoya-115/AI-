# 守山店 売上マッピング仕様(日報 → 2026 売上現状)

**ステータス: 確定(2026-09-10、セル座標ベースで検証済み)。数値は含みません(具体的な金額は `accounting/output/` 配下のGit管理対象外領域を参照)。**

## 目的

守山店の日報(`①8月.xlsx`)から、「2026 売上現状」と一致する税抜の新規・既存・物販売上を再現する計算ルールを確定すること。

## 検証方法

オーナーが日報「①8月.xlsx」をGoogle Driveへ読み取り専用ミラーとしてコピーし、そのGoogle Drive経由でExcel原本(.xlsx)をバイナリのまま取得できることを確認した上で、`openpyxl`でセル座標・結合セル・数式・保存済み計算値を保持した状態で解析しました。Dropbox原本・Google Driveミラー・「2026 売上現状」「2026店舗収支」のいずれも変更していません。

## シート構成(確定)

`基本情報`, `1`〜`31`(日別), `スタッフ1`〜`スタッフ6`, `スタッフ集計`, `在庫帳`, `月報集計` の41シート。

## 日別シート(例:シート「1」=8月1日)の構造(確定)

- ヘッダー行: 3行目。データ行: 4行目〜53行目(顧客・取引単位、最大50行)。53行目までで収まらない場合の予備行が58〜62行目に別途存在(税抜換算は簡易式のみで、通常未使用)。
- 54行目が「その日の合計」行(各列に`SUMIF(範囲,">0")`が設定されている)。

### 確定した列とヘッダー名の対応(シート「1」の例、他日も同一レイアウト)

| 列 | ヘッダー名 | 内容 | 税区分 |
|---|---|---|---|
| B | 顧客名 | 顧客名(空欄の行もあり得るが、金額計算には影響しない) | - |
| C | 担当 | 担当スタッフ名 | - |
| D | 新規/既存 | その来店が「新規」「既存」かのラベル(物販のみの来店では「物販」等、空欄の場合もある) | - |
| F | コース内容 | 施術コース名 | - |
| J | 販売商品 | 物販の商品名 | - |
| K | 販売数 | 物販の数量 | - |
| M | 新規売 | 新規客の施術売上(税込)。`=VLOOKUP($F,基本情報!$F$4:$H$55,3,FALSE)` | 税込 |
| N | 新規チケット | 新規客が回数券等を購入した場合の税込金額 | 税込 |
| O | 既存売 | 既存客の単発・回数券購入(税込) | 税込 |
| P | 物販 | 物販売上(税込) = 販売数×単価 | 税込 |
| U | 差引新規売 | `=SUM(M:N)-R(値引)` | 税込 |
| V | 差引回数券 | `=O-S(値引)` (既存客分) | 税込 |
| W | 差引物販 | `=P-T(値引)` | 税込 |
| X | 最終売上 | `=SUM(U:W)` | 税込 |
| **AC** | **新規売（税別）** | **`=U/1.1`(新規売上を標準税率10%で税抜化)** | **税抜** |
| **AD** | **回数券（税別）** | **`=V/1.1`(既存客の単発・回数券購入を標準税率10%で税抜化)** | **税抜** |
| AE | (非表示の補助列) | 物販商品の税率(1.1または1.08)を`基本情報`からVLOOKUPで取得 | - |
| **AF** | **物販（税別）** | **`=IFERROR(W/AE,0)`(物販は商品ごとの実際の税率で税抜化。標準10%・軽減8%が商品単位で自動判定される)** | **税抜** |
| **AG** | **累計（税別）** | **`=AGGREGATE(9,6,AC:AD,AF)`(その行のAC+AD+AFの合計、エラー無視)** | **税抜** |
| AB | 累計（税込） | `=X`(税込ベースの行合計) | 税込 |

### 54行目(日合計)の確定セル

| セル | 内容 |
|---|---|
| AC54 | `=SUMIF(AC4:AC53,">0")` → その日の新規売上合計(税別) |
| AD54 | `=SUMIF(AD4:AD53,">0")` → その日の既存売上合計(税別) |
| AF54 | `=SUMIF(AF4:AF53,">0")` → その日の物販売上合計(税別) |
| AG54 | `=SUMIF(AG4:AG53,">0")` → その日の合計(税別) = AC54+AD54+AF54 |

## 確定した税抜計算ルール

1. **新規売・回数券(既存)は、店舗の日報自体が標準税率10%として一律`÷1.1`で税抜化している。** これは会計AI側の推測ではなく、日報ファイル自身に埋め込まれた数式であり、店舗側の既存の会計運用そのものです。
2. **物販は、日報が商品ごとに`基本情報`シートの税区分(標準税率1.1 / 軽減税率1.08)をVLOOKUPで参照し、商品単位で正しい税率で税抜化している。** 一律`÷1.1`ではなく、商品ごとに実際の税率を判定する仕組みが既に実装されています。
3. **「2026 売上現状」の新規・既存・物販・累計は、上記のAC54・AD54・AF54・AG54(税別)に対応します。**

## 8月1日〜9日の一致検証結果

日別シートのAC54・AD54・AF54・AG54(税別)を、「2026 売上現状」の守山店8月1日〜9日の新規・既存・物販・累計と1日ずつ突き合わせました。

- **7/9日(8/1, 8/2, 8/3, 8/4, 8/5, 8/7, 8/9)は完全一致(誤差は浮動小数点の丸めのみ)。**
- **2/9日(8/6, 8/8)に差異あり。原因を行レベルで特定済み(推測ではなく、該当行の実データで確認)。詳細は `accounting/output/` 配下のGit管理対象外ノートに記録。**
  - 8/6: 物販の差異は、同一顧客の2件目の物販購入行(顧客名欄が空欄の行を含む)が「2026 売上現状」側の集計に含まれていないことが原因。
  - 8/8: 新規と既存の内訳がちょうど同額だけ入れ替わっている(合計は一致)。原因は、顧客名欄が空欄の既存客の回数券購入行の扱いの違い、または日報側のコース名と区分(D列)の不整合(区分は「既存」だが、コース名が新規客向けの「美骨新規」になっている行が別に存在)と考えられる。
- いずれのケースも、「2026 売上現状」の最終更新日(2026-08-10)より後に日報側が更新・修正された可能性と整合する(日報のGoogle Driveミラーは2026-08-18〜19時点のスナップショット)。

## 月報集計との整合性(確定)

`月報集計`の「実売(実績)」「内物販」の月合計は、日別シートのAG54・AF54を31日分合計した値と一致することを確認しました(誤差は丸めのみ)。

ただし、`月報集計`の「内回数券等」は「新規売(税別)+既存売(税別)」の合算値であり、新規と既存を単独では区別していません(`月報集計`のセルC6=`C5-C7`という式で、実売実績から内物販を差し引いた残りとして算出されているため)。したがって、新規・既存を分けて確認する場合は、日別シートのAC54・AD54を直接参照する必要があります。`月報集計`の「新規」行(B12)は金額ではなく客数(件数)です。

## 未確定・要確認の点

- 8/6・8/8の差異そのものの是正方法(日報側を正としてよいか、「2026 売上現状」側を修正すべきか)は、オーナーの判断が必要です。推測で埋めていません。
- 標準10%一律の新規売・既存売の税区分判定が、将来的に軽減税率対象の役務(現時点では想定されていない)にも当てはまるかどうかは未確認です。
